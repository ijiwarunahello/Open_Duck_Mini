# 秋月パワーLEDリフレクターキット用プロジェクター部品

秋月電子「基板付パワーLEDリフレクターキット」(販売コード 106077) を、キット全部（ナカザ反射鏡 Φ20、BJB レンズホルダー 47.313.-320、BJB LED コネクタ 47.313.1000）のまま収める `flash_light_module` の改造版。`flash_reflector_interface.stl` は使わない。

| ファイル | 内容 |
| --- | --- |
| `flash_light_module_akizuki.stl` | 本体（`flash_light_module.stl` の代わりに印刷） |
| `flash_light_module_akizuki_test.stl` | 前側 16mm だけのテスト片（はまり具合の確認用） |
| `make_module.py` | 上流の `flash_light_module.stl` を加工して上の 2 つを生成するスクリプト |

## 形の要点

- 頭部に接着する面は上流のまま。耳と電線の出口がある頭部と反対側だけ、外径を太らせた。
- コネクタの外形（本体、端子ブロック 2、ねじ耳 2）を前面まで通したくぼみで、前から真っすぐ入れる。向きは 1 つに決まる。
- 耳の位置に M2.6 タッピングねじの下穴（Ø2.2、深さ 6mm）。
- 電線は端子を出てすぐ後ろへ曲げ、Ø2.8 の斜めの穴から中心の通路を通り、頭部側の Ø4 の穴（後ろ端から 6mm、軸と同じ高さ）へ出す。

## 組み立て

1. LED 付き星形基板にコネクタを付け、電線（20〜22AWG）を挿す。挿すとロックし、抜くと再使用できない。
2. 電線を後ろへ曲げ、底の穴に通して頭部側の穴から引き出しながら、コネクタを入れる。
3. 耳を M2.6 タッピングねじで止める。
4. 反射鏡を入れたホルダーを前から押し込んで、コネクタにはめる。

## 再生成

```
uv run --no-project --with trimesh --with manifold3d --with shapely \
    --with networkx --with scipy --with rtree python make_module.py
```

キットの寸法は `make_module.py` 先頭の定数（2026-11-21 にノギスで実測）。端子ブロックの位置と電線の出る向きは、秋月のマニュアル PDF の寸法図から読み取った値。
